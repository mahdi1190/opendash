# The garden's music

The songs in this folder were made by the owner of OpenDash with [Suno](https://suno.com). They are
**not** covered by the MIT licence of the code: the licence in the top folder applies to the code and
documentation only. You may play them inside OpenDash; ask before using them anywhere else.

How the garden picks them, and how to add one (drop a file with the right name): `docs/dev/GARDEN_MUSIC.md`.

| File | Title | Plays |
| --- | --- | --- |
| `dawn-1.mp3` | Dewlight Morning | dawn, 05:00 to 08:00 |
| `morning-1.mp3` | Morning Marimba | morning, 08:00 to 12:00 |
| `morning-2.mp3` | Morning Porch Melody | morning, 08:00 to 12:00 |
| `afternoon-1.mp3` | Sunny Game Loop | afternoon, 12:00 to 17:00 |
| `afternoon-2.mp3` | Sunny Game Loop (a second take) | afternoon, 12:00 to 17:00 |
| `evening-1.mp3` | Golden Evening in the Village | evening, 17:00 to 20:00 |
| `night-1.mp3` | Lakeside at Night | night, 20:00 to 24:00 (and late night, 00:00 to 05:00, until it has its own) |

`levels.json` holds each file's level trim in dB, measured so the songs sit together and under the
garden's nature sounds.
